\chapter*{\centering Abstract}
\addcontentsline{toc}{chapter}{Abstract}

This thesis presents OptiVision, a next-generation e-commerce platform for the online sale of eyeglasses. The project digitizes the role of the human optician by integrating three core technologies: Face Shape Classification, 3D Virtual Try-On, and an AI Chatbot. The system uses a hybrid model (MediaPipe and a CNN) trained on the CelebA dataset to classify face shapes with 91.5\% accuracy. This geometric data anchors 3D glasses models for real-time virtual try-on, while the AI chatbot filters the catalog to provide personalized styling recommendations.

\vspace{0.3cm}
\noindent\textbf{Keywords:} E-commerce, Face Shape Classification, Virtual Try-On, Chatbot.

\chapter*{\centering Résumé}
\addcontentsline{toc}{chapter}{Résumé}

Cette thèse présente OptiVision, une plateforme de commerce électronique de nouvelle génération pour la vente de lunettes. Le projet numérise le rôle de l'opticien humain en intégrant trois technologies : la classification de la forme du visage, l'essayage virtuel 3D et un chatbot IA. Le système utilise un modèle hybride (MediaPipe et un CNN) entraîné sur le jeu de données CelebA pour classifier la forme des visages avec 91,5 \% de précision. Ces données ancrent des modèles 3D pour un essayage en temps réel, tandis que le chatbot filtre le catalogue pour offrir des recommandations personnalisées.

\vspace{0.3cm}
\noindent\textbf{Mots-clés:} E-commerce, Classification de Formes de Visage, Essayage Virtuel, Chatbot.
